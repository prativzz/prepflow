# PrepFlow

**PrepFlow** is an AI-powered interview preparation platform that generates personalized mock interviews, analyzes resumes, improves ATS compatibility, evaluates responses, tracks performance, and helps candidates become interview-ready.

## Tech Stack

### Frontend
- React (JavaScript)
- Vite
- Tailwind CSS
- React Router
- Zustand
- TanStack Query
- Axios
- React Hook Form
- Zod
- Framer Motion

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- Multer
- Cloudinary

## Project Structure
- `frontend/` - Contains the React application
- `backend/` - Contains the Node.js API server
